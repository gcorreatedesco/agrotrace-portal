Guía de Procedimiento

Configuración de Email
Transaccional en AgroTrace

Cómo configurar el envío de emails de autenticación (invitaciones, recuperación de contraseña, confirmaciones) usando Supabase y un servicio SMTP externo.

Documento: AgroTrace_Guia_SMTP_Email
Versión: v1.0
Fecha: Junio 2026

1. Concepto general

Cuando un usuario se registra, recibe una invitación o pide recuperar su contraseña, el sistema necesita enviarle un email automático. Este proceso se llama email transaccional — a diferencia del email de marketing, es uno a uno, disparado por una acción concreta del usuario.

No necesitás servidor propio Supabase actúa como intermediario entre tu aplicación y el servicio de email. Vos configurás las credenciales una sola vez en el dashboard de Supabase, y el sistema se encarga del resto. No hay infraestructura que mantener.

Diagrama del flujo

UsuarioPide invitación o reset
→
AgroTraceLlama a Supabase SDK
→
Supabase AuthGenera el link
→
Resend / SendGridEntrega el email
→
UsuarioRecibe en su casilla

3. Servicios SMTP recomendados

Todos los servicios listados son SaaS — te registrás, obtenés credenciales, y las pegás en Supabase. No hay nada que instalar ni mantener.

Servicio Plan gratuito Dominio propio Recomendado para
Resend — resend.com 3.000 emails/mes Sí Primera opción. API moderna, fácil de configurar con Supabase, soporte en español.
SendGrid — sendgrid.com 100 emails/día Sí Muy establecido. Más complejo de configurar pero ampliamente documentado.
Brevo (ex Sendinblue) 300 emails/día Sí Buena opción si querés también envíos de marketing en el futuro.
Mailgun — mailgun.com 1.000 emails/mes (3 meses) Sí Robusto para volúmenes medios. Requiere tarjeta de crédito para registrarse.

4. Procedimiento paso a paso (con Resend)

Se usa Resend como ejemplo por ser la opción más simple de integrar con Supabase. El procedimiento con los otros servicios es equivalente.

Parte A — Configurar Resend

  • 1
    Crear cuenta en Resend
    Ir a resend.com → Sign up con tu email de Gmail o institucional. No requiere tarjeta de crédito.
  • 2
    Obtener API Key
    En el dashboard de Resend: API Keys → Create API Key. Copiar la clave generada (empieza con re_). Guardarla en un lugar seguro — solo se muestra una vez.
  • 3
    Verificar dominio (opcional pero recomendado)
    Si tenés un dominio propio (ej: agrotrace.com.ar), podés verificarlo en Resend para enviar desde noreply@agrotrace.com.ar. Sin dominio propio, los emails salen desde el dominio de Resend, lo cual está bien para empezar.

Parte B — Configurar Supabase

  • 4
    Ir a configuración SMTP en Supabase
    En el dashboard de Supabase:
    Project Settings → Authentication → SMTP Settings
    Activar el toggle "Enable Custom SMTP".
  • 5
    Completar los campos SMTP
    Con los datos de Resend, completar:
    Host: smtp.resend.com Port: 465 Username: resend Password: [tu API Key que empieza con re_] Sender email: noreply@tudominio.com (o el que te dé Resend) Sender name: AgroTrace
  • 6
    Guardar y enviar email de prueba
    Hacer clic en "Save". Supabase ofrece un botón "Send test email" — usarlo para confirmar que la conexión funciona antes de seguir.

Parte C — Personalizar los templates de email

  • 7
    Ir a Email Templates
    En Supabase: Authentication → Email Templates. Hay 4 templates editables.
  • 8
    Editar cada template en español
    Templates disponibles y su uso en AgroTrace:
    Template Cuándo se envía
    Confirm signup Cuando un usuario nuevo se registra y debe confirmar su email
    Invite user Cuando el RT invita a un operador con inviteUserByEmail()
    Magic Link Login sin contraseña (opcional — no usamos por ahora)
    Reset password Cuando el usuario hace clic en "Olvidé mi contraseña"
  • 9
    Ejemplo de template "Invite user" en español
    Reemplazar el contenido por defecto con algo similar a:
    <h2>Bienvenido a AgroTrace</h2> <p>Fuiste invitado a unirte al sistema de trazabilidad AgroTrace.</p> <p>Hacé clic en el siguiente botón para crear tu contraseña y activar tu cuenta:</p> <a href="{{ .ConfirmationURL }}">Activar mi cuenta</a> <p>Este enlace expira en 24 horas.</p> <p>Si no esperabas este email, podés ignorarlo.</p>
    La variable {{ .ConfirmationURL }} es reemplazada automáticamente por Supabase con el link real.

5. Variables disponibles en los templates

Variable Contenido
{{ .ConfirmationURL }} Link de confirmación o activación generado por Supabase
{{ .Email }} Email del destinatario
{{ .SiteURL }} URL base del proyecto (configurada en Supabase)
{{ .Token }} Token OTP de 6 dígitos (para flujos sin link)

6. Flujo de invitación de usuarios en AgroTrace

Cuando el sistema de gestión de usuarios esté implementado, el flujo de invitación será:

  • 1
    RT invita a un operador desde el portal
    Ingresa el email del nuevo usuario y selecciona su rol. El sistema ejecuta:
    const { data, error } = await sb.auth.admin.inviteUserByEmail( 'operador@ong.org', { data: { rol: 'ong', organizacion_id: 'xxx' } } );
  • 2
    Supabase envía el email automáticamente
    Usando el template "Invite user" personalizado, enviado vía Resend (o el SMTP configurado).
  • 3
    El nuevo usuario hace clic en el link
    Es redirigido a AgroTrace donde define su contraseña. Su cuenta queda activa con el rol asignado.
  • 4
    Se crea automáticamente su perfil
    Un trigger en Supabase inserta el registro en la tabla perfiles con el rol y organización correctos. El RT no necesita intervenir más.
Estado en AgroTrace El módulo de gestión de usuarios (invitaciones desde el portal RT) está pendiente de implementación. Este documento describe el procedimiento a seguir cuando se desarrolle esa funcionalidad. Por ahora, los usuarios se crean manualmente desde el dashboard de Supabase.
